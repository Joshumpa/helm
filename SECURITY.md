# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| v1.x (current) | Yes |

## Reporting a Vulnerability

**Do not open a public issue for security vulnerabilities.**

Report vulnerabilities by email to: **joshua.marinez@stjsonora.gob.mx**

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

You will receive a response within 72 hours. If the vulnerability is confirmed, a fix will be prioritized and a patched release issued. You will be credited in the release notes unless you prefer to remain anonymous.
